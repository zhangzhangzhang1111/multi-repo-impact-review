# C++ 编码规范与基础审核

## 编码规范

- 遵循仓库现有格式、命名和头文件规则；接口表达所有权、可空性、生命周期、线程约束和错误语义。
- 优先 RAII、标准容器和有界字符串处理；避免裸所有权、未初始化对象、悬空引用、越界、整数溢出、符号转换和数据截断。
- `sprintf`、`strcpy`、`memcpy` 等操作必须证明目标容量、终止符、重叠条件和实际长度安全。
- 外部接口处理空返回、超时、错误码、类型或协议不匹配、部分结果和重试边界；析构与异常路径必须释放资源。
- 共享状态说明锁、原子性、回调线程和对象存活期；不得在持锁区执行无界后台调用。
- 保持 ABI、协议、配置和新老客户端兼容；券商定向逻辑使用明确开关、默认值和回退路径。
- 日志、告警和降级覆盖可恢复异常，不记录密码、Token、完整账户或其他敏感数据。
- 评估热点循环、复制、分配、锁竞争、后台交互、配置和数据库访问的延迟及并发上限。
