# Runtime binaries

The source repository intentionally excludes large native executables. Each GitHub Release package injects exactly one unmodified official `codebase-memory-mcp v0.10.2` binary for its target platform under this directory.

Download a complete offline package from the project Releases page. Upstream provenance, license, notices, SBOM, and release checksums are kept in `vendor/codebase-memory-mcp/`.
